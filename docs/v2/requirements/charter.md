# V2 公司章程核对 · 设计草案

系统按清单展示原文与出处。办理人逐条接受或拒绝，拒绝需原因。布局采用材料页签、上方状态与完成动作、左侧原件和右侧摘录，两栏各自滚动。下一条在当前样本中循环，点出处才驱动原件定位。

| 场景 | 后端事实来源草案 | 操作 | 联调预期 |
|---|---|---|---|
| 处理中 | run 状态及处理步骤 | 等待、查看状态 | 完成返回 RUN_NOT_READY |
| 缺材料 | run 文件快照及检查结果原因 | 补传；原型仅提示 | 按最终缺材料规则验收，待产品确认 |
| 正常未找到 | 全部必查窗口成功覆盖，结果无证据 | 人工接受或拒绝 | 按正常核对计入统计 |
| 覆盖不全 | 必查窗口未覆盖及受影响项 | 核对已有合法摘录 | 409 COVERAGE_INCOMPLETE，完成状态零写入 |
| 正常核对 | run 就绪，覆盖完整，有当前版本结果 | 定位与确认 | 全部处理后完成 |
| 已完成 | 当前任务已写入完成状态及已完成 run | 看历史决定及出处 | 只读 |

样本中的缺材料场景用于界面评审。其他材料、上传入口和接口联调在后续实现。
