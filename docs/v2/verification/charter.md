# 章程核对验证

用 [根 README](../../../README.md) 启动静态原型。原始公开 15 页样本固定在 V1 SHA，当前线框取第 14、15 页的局部摘录和对应的坐标线框，后续联调再验证原 PDF 的定位。可通过场景选择切换处理中、缺材料、两类覆盖不全与完成只读。

1. 点「第 15 页」出处，左侧显示已定位页和标记，右侧可独立滚动。
2. 点「下一条待办」多次检查环回。试拒绝空原因、保存合法原因，再接受剩余条目，点击完成后刷新，检查历史决定。
3. 在两个覆盖不全场景检查有效摘录仍可确认、完成禁用。此处是 UI 模拟行为。
4. 联调后对两类故障分别实测后端 409 且任务未写完成，正常对照完成 200。记录受影响项、保留出处、HTTP 与数据库结果。
