# 业务术语

| 术语 | 定义 |
| --- | --- |
| 用户 | 登录网站的业务人员；拥有自己的任务和材料 |
| 法人客户 | 材料所对应的企业，与网站登录用户不是同一概念 |
| 客户类型 | 本次被核对法人的业务角色：借款人、保证人、抵（质）押人 |
| 核对任务 | 一个用户针对一种客户类型组织的一次资料核对；可含多份同类材料 |
| 材料类别 | 营业执照、公司章程、最近一年已审计财报等业务分类 |
| 文件 | 一份上传的PDF或图片；同类材料可以有多个文件 |
| 检查清单 | 某产品及客户类型需要查找的固定问题集合 |
| 检查项 | 清单中可返回证据或未找到的叶子问题 |
| 原文块 | OCR识别出的段落、标题、表格、印章等内容及其来源位置 |
| 裁剪图 | OCR从某页识别出的局部图像，如印章或签名 |
| 证据 | 从原件找到的文字、完整表格、或印章/签名及其识别文字 |
| 查找结果 | 某检查项的一条证据，或者一条明确的未找到结果 |
| 候选 | 已有依据表明与目标检查项相关，但可能仍需人工核对对应关系的证据 |
| 未找到 | 本轮正常查找没有得到可对应的证据；不证明材料不存在，也不表示技术失败 |
| 人工确认 | 对一条查找结果选择接受或拒绝；拒绝须说明原因 |
| 接受 | 认可当前查找结果，包括认可“未找到”；不表示贷款通过合规审查 |
| 拒绝 | 不认可当前查找结果；不直接等于企业或贷款不合规 |
| 核对完成 | 所有应确认结果已选择且拒绝原因完整，本次任务结束 |
| 输入修订 | 一次文件集合或人工分类的变更后形成的核对输入状态 |
| 处理批次 | 基于确定输入修订和清单版本执行的一轮分类、查找与证据整理 |
| 结果集 | 一个处理批次最终可供人工核对的全部查找结果 |
| 清单待配置 | 系统缺少该客户类型的有效清单，与“材料未上传”不同 |
