# 验收与测试计划

需求原有AC01–AC45继续适用，以V0.5覆盖旧角色规则；以下为开发专项补充。测试应验证行为和数据，不仅验证按钮或HTTP200。使用独立测试DB和临时文件目录，禁止测试默认外发真实资料。

## 1. 功能与隔离

| ID | 场景 | 必须证明 |
| --- | --- | --- |
| T01 | 登录眼睛显隐/失败/退出/过期 | 输入不丢；失败不跳转；退出旧sid失效，缓存清除；无注册找回接口 |
| T02 | A/B账号隔离 | 列表、详情、文件、裁剪、下载、结果、确认、阅读状态及后台响应均不串用户；猜中ID仍404 |
| T03 | 类型禁用 | 首页后两角色灰色不可点，直接POST该role也拒绝；无空清单完成 |
| T04 | 同类多文件 | 均可上传、分类、参与查找与定位，不能只保留最后一份 |
| T05 | 修改输入 | 增删换/改分类建立修订；受影响项重确认，未影响材料确认保留且可追踪 |
| T06 | 结果分组 | 第十二/十八条同标题、各确认；多个图像候选独立确认计数 |
| T07 | 状态机 | 接受/拒绝只留一个按钮；hover/键盘提示；二次点击清原因；空白原因阻止完成 |
| T08 | 统计 | N=U+A+R；原因空计M；N=0比例null且不可完成；19仅为fixture |
| T09 | 完成事务 | 所有材料一起校验；有拒绝但原因完整允许完成；完成后直接调写API也被拒绝 |
| T10 | 阅读与切换 | 同功能切任务、原件/清单独立滚动、同类文件来源跳转；刷新恢复阅读与确认 |
| T11 | 长内容 | 1280×720下长原因、宽表、长清单和侧栏拖宽不遮挡或丢值 |
| T12 | HTML内容 | OCR表格脚本、onerror、外部资源不能执行/加载，rowspan/colspan保留 |

## 2. 后台作业与并发

| ID | 故障注入 | 通过标准 |
| --- | --- | --- |
| T13 | 入队前后事务回滚 | 不出现业务run已提交却永久无job；事务回滚也不启动半条任务 |
| T14 | 相同Idempotency-Key连点开始 | 返回同run，最多一个活跃外部提交；不同body同key拒绝 |
| T15 | 保存jobId后强杀worker | 恢复查同jobId，不重新提交OCR；截止时间不重置 |
| T16 | POST发出但响应中断 | SUBMISSION_UNKNOWN可见，不无限自动重交 |
| T17 | 同用户两窗口写同decision版本 | 一个成功，另一个412；无静默丢原因或双增计数 |
| T18 | 完成与上传/删除并发 | task行事务约束；最多一方满足状态，完成任务不会后来又被改文件 |
| T19 | A任务切B后A响应迟到 | A结果更新A缓存，B界面/统计/原因不被覆盖 |
| T20 | 新修订开始后旧run完成 | 旧批次SUPERSEDED不可发布；当前结果仅来自新run |
| T21 | 5账号并发 | 5个独立会话同时浏览/上传/核对；无跨账号泄露，DB连接不耗尽，OCR≤1/LLM≤2；排队可见 |
| T22 | 外部429/5xx/超时/401 | 有界退避、错误可诊断；认证错误不无限重试；不回退假数据 |

5用户自动化使用5个独立浏览器context或5份Cookie/CSRF会话，不是同Cookie开5个标签。先用受控假服务做长时/错误注入，再以真实服务少量并发确认配额。纯业务API性能记录硬件、样本、请求数、p50/p95和错误率；初始目标p95≤1秒，外部排队及模型时间单独列，不把假服务时延当真实服务。

## 4. LLM评价样本与门槛

开发期准备人工标注的小样本集：建议至少营业执照5份、章程5份、审计财报5份，覆盖清晰/扫描、同类多文件、未找到、多条款、多候选及末页证据。用户现有两份OCR快照只够验证部分适配，不够证明整体准确率。文件与标注不随公共仓库提交。

记录材料分类正确率、检查项证据召回、引用有效率、文字截取一致性、未找到误报、图像匹配正确率、耗时/调用数。引用归属与从原文截取一致性要求100%，属于代码可验证约束；业务召回/识别的数字目标待拿到代表性样本后制定，不能把另一行内OCR项目的95%指标直接当本项目已确认准出线。任何错误来源或模型编写的“原文”都视为阻断问题。
